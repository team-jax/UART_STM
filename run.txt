STM32 로봇 손 — 작동시키는 법 (요약)

★ 가장 쉬운 방법 (2026-07-13 펌웨어부터): 보드의 파란 USER 버튼
   - 전원 켜면 초록 LED(PD12)가 3회 점멸 = 펌웨어 정상 부팅
   - 부팅 0.5초 후 홈잉: 손가락 서보가 0.15초 간격으로 하나씩 OPEN 위치로 이동
     (홈잉 중 LED 깜빡임, 끝나면 꺼짐)
   - 파란 버튼을 누를 때마다 GRIP ↔ OPEN 토글 (LED도 같이 토글됨)
   - 케이블/어댑터/배선 전혀 불필요

★ 손가락별 각도 캘리브레이션 — 실시간 도구 (추천)
   보드 USB 연결된 상태에서 터미널에:
     ./tools/calibrate.py
   키보드로 손가락을 실시간으로 움직이며 맞추는 도구 (SWD 경유, UART 불필요):
     w/s = ±5도, W/S = ±1도  ← 누르는 즉시 손가락이 움직임
     o = 지금 위치를 "펴기"로 저장,  g = 지금 위치를 "쥐기"로 저장
     1~6 또는 n/p = 손가락 선택,  h = 전체 펴기 정렬 확인,  q = 종료
   종료하면 main.c 자동 반영 + 빌드/플래시까지 해줌 (y/N 물어봄)
   ※ 캘리브레이션 중 파란 버튼 누르지 말 것

★ 수동 캘리브레이션 (직접 고치고 싶을 때)
   src/main.c 에서 "fingerTable" 검색 → 손가락별 {OPEN 각도, GRIP 각도} 숫자만 수정:
     { &htim3, TIM_CHANNEL_1, 180.0f, 30.0f },  /* FINGER1_A / PA6 */
   수정 후 재빌드+플래시:
     ~/.platformio/penv/bin/pio run -t upload
   홈잉과 버튼 제스처 모두 이 표를 따라감
   ※ 참고: 보드 확인 결과 실제 칩은 F407VG(1MB, Discovery 계열)이고,
     내장 ST-Link의 시리얼(VCP)은 MCU에 배선되어 있지 않음 → 그래서
     USB-C만으로는 UART 명령이 불가능. UART를 쓰려면 아래 2-A 참조.
   ※ 어깨 서보(ID0)는 PA0 → PA15로 이동됨 (PA0은 버튼이 사용)

0. 전원 (보드 켜기 전 확인)
   - 서보 전원은 외부 5~6V (보드 5V 핀 사용 금지)
   - 외부 전원 GND ↔ STM32 보드 GND 반드시 연결
   - 손가락 사이에 물체 없는 상태로 시작

1. 펌웨어 굽기 (ST-Link 연결 후)
   ~/.platformio/penv/bin/pio run -t upload

2. UART 배선 — 둘 중 하나
   설정 공통: 115200 baud, 8-N-1

   A) 별도 USB-UART 어댑터가 있으면:
      어댑터 RX → PA9 (보드 TX)
      어댑터 TX → PA10 (보드 RX)
      GND 공통

   B) 어댑터 없으면 — ST-Link V2-1 내장 시리얼(VCP) 사용:
      ST-Link의 TX 핀 → 보드 PA10
      ST-Link의 RX 핀 → 보드 PA9
      (GND는 SWD 배선으로 이미 공통. Mac에서는 /dev/cu.usbmodem* 으로 잡힘)
      ※ ST-Link에 TX/RX 핀이 없는 미니 동글이면 이 방법 불가 →
        버튼(K0/K1)으로 GRIP/OPEN 토글하는 펌웨어로 바꿔야 함 (Claude에게 요청)

3. 명령 보내기 — 방법 A (추천): 스크립트
   ./tools/hand.py grip     # 손 쥐기  (AA F0 00 01 F1)
   ./tools/hand.py open     # 손 펴기  (AA F0 00 00 F0)
   ./tools/hand.py 4 90     # 개별 서보: ID4를 90.0도로
   포트 자동 탐지. 여러 개면: ./tools/hand.py grip --port /dev/cu.usbserial-xxxx

4. 명령 보내기 — 방법 B: zsh만으로
   ls /dev/cu.*                                  # 포트 이름 확인
   exec 3<>/dev/cu.usbserial-0001                # 포트 열어두기
   stty -f /dev/cu.usbserial-0001 115200 cs8 -cstopb -parenb raw
   printf '\xAA\xF0\x00\x01\xF1' >&3             # GRIP
   printf '\xAA\xF0\x00\x00\xF0' >&3             # OPEN
   exec 3>&-                                     # 포트 닫기
   ※ exec로 포트를 열어둔 채 보내야 함 (닫히면 macOS가 baud 설정을 초기화)

5. 안 움직일 때 점검 순서 (CLAUDE.md STEP 4-2)
   1) 펌웨어를 실제로 굽었는지 (pio run -t upload 성공 로그 확인)
   2) TX/RX 교차 확인 (어댑터 TX ↔ 보드 PA10)
   3) 서보 외부 전원 ON + GND 공통 재확인
   4) 개별 명령 테스트: ./tools/hand.py 4 90
   5) 여전히 안 되면 배선 사진 + 증상 들고 Claude한테 보고
